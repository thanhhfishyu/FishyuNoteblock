Note Block Song Builder

Biến file MIDI hoặc NBS thành mạch note block + redstone, xuất ra .litematic (Litematica) và .schem (WorldEdit). Mọi thứ chạy ngay trong trình duyệt, file của bạn không được tải lên đâu cả.

1 Chọn bài nhạc

Kéo thả file vào đây hoặc bấm để chọn
Hỗ trợ .mid .midi .nbs (Open Note Block Studio)

2 Cân bằng nốt & nhạc cụ

Minecraft chơi theo nhịp 0,1 giây, mỗi nhạc cụ chỉ có 2 quãng tám. App tự chọn nhạc cụ, quãng tám và khối đặt dưới note block; bạn có thể chỉnh từng track bên dưới.

3 Kích thước & kiểu mạch

Nếu bài quá dài so với diện tích, mạch tự leo lên tầng trên (bằng cột đuốc redstone) và chạy tiếp. Mỗi tầng cao 4 khối; với kiểu "chồng lên nhau" mỗi tầng cao 4 × số làn.

4 Kết quả

Trên trang Claude, file được tải về dạng .zip: giải nén ra để lấy file .litematic / .schem. Bản trên GitHub Pages thì tải thẳng.
Kéo chuột trái: xoay · chuột phải hoặc Shift+kéo: di chuyển · cuộn: phóng to · điện thoại: 1 ngón xoay, 2 ngón di chuyển/phóng to

Vật liệu cần

Cách dùng trong game

  1. Chép file .litematic vào thư mục .minecraft/schematics, mở menu Litematica (phím M) → Load Schematics → chọn bài → Load.
  2. Đặt sát mặt đất bằng phẳng: khối cát (trống snare) cần có khối đỡ bên dưới, không thì sẽ rơi.
  3. Phía trên mọi note block phải là không khí, nên đừng đặt mạch sát trần.
  4. Chơi creative thì dán thẳng (paste). Chơi survival thì xây theo hình mờ: số trên mỗi note block là số lần bấm chuột phải để chỉnh nốt.
  5. Mạch nhiều tầng: các tầng nối với nhau bằng cột đuốc redstone ở mép. Bạn có thể xây sàn nhà xen giữa các tầng, miễn là không chạm vào cột đuốc và phía trên note block vẫn trống.
  6. Bấm nút đá ở đầu mạch (ô viền xanh lá trong hình xem trước) để phát nhạc.
  7. Dùng WorldEdit thì lấy file .schem: //schem load tên rồi //paste.

Muốn dùng phần cân bằng của Note Block Studio: cân bằng xong trong NBS thì lưu file .nbs (Save song) rồi thả vào đây, đừng dùng Export schematic của NBS.
